# Sumo Arena — 3D-игра по сети с физикой

Шары сталкивают друг друга с парящей арены в лаву. Кто первым набрал 7 очков — победил.
Физика (cannon-es) считается на сервере, браузер рисует картинку на Three.js, поэтому у всех в комнате одна и та же игра.

## Управление
- **WASD** — движение, **Пробел** — прыжок, **Shift** — рывок (удар сильнее, перезарядка 1.5 с)
- **Мышь** (клик по игре) или **Q/E** — камера, **M** — звук

## Боты
При создании комнаты можно выбрать число ботов (до 7) и сложность: лёгкая, средняя, сложная.
Внутри игры кнопки **+** и **−** (слева вверху) добавляют и убирают ботов. Если в комнате не осталось мест, а заходит человек, один бот уступает ему место.
Боты работают на сервере (`server/bot.js`): ищут ближайшего соперника, заходят с внутренней стороны арены, делают рывок и держатся подальше от края. Читов у них нет, физика та же, что у людей.

## Запуск
```bash
npm install
npm start
```
Сервер напечатает адреса вида `http://localhost:3000` и `http://192.168.x.x:3000`.

## Играть с другом
- **В одной Wi-Fi сети:** друг открывает адрес с `192.168...`, который напечатал сервер.
- **Через интернет:** задеплойте на Render (есть `render.yaml`) или временно откройте порт туннелем (например, cloudflared / ngrok): `ngrok http 3000`.
- Один заходит и нажимает «Играть», потом «Скопировать ссылку» и отправляет другу. Или оба вводят один и тот же код комнаты.

## Тесты
```bash

```

## Структура
- `server/` — HTTP + WebSocket, комнаты, физика (`room.js`), боты (`bot.js`)
- `client/` — сцена Three.js, ввод, сеть, звук
- `shared/config.js` — общие настройки игры
- `test/` — тесты физики и сети
